# Mi Proyecto de Mensaje Personalizado

Este es un proyecto simple creado con **Node.js** que muestra un mensaje con un diseño básico y que se puede hacer público usando `ngrok`.

## Tecnologías utilizadas

- **Node.js**: Un entorno de ejecución para JavaScript en el lado del servidor.
- **HTML**: Para la estructura de la página web.
- **CSS**: Para estilizar el mensaje.

## Requisitos

Para ejecutar este proyecto en tu máquina local, asegúrate de tener lo siguiente instalado:

- [Node.js](https://nodejs.org/): La plataforma para ejecutar el código JavaScript en el servidor.
- [ngrok](https://ngrok.com/): Para exponer el servidor local al público (opcional).
